# مود FreeLife RP برای GTA San Andreas اندروید

این پوشه یک افزونهٔ مستقل و اولیه است؛ فایل‌ها و دارایی‌های خود بازی را جایگزین نمی‌کند.

## وضعیت نسخهٔ 0.1.0
- نمایش HUD نقش‌آفرینی روی صفحهٔ بازی
- نمایش سلامت واقعی شخصیت از داخل بازی
- نمایش اولیهٔ شغل شهروند، پول، گرسنگی و تشنگی

نکته: پول، شغل، گرسنگی و تشنگی در این نسخه فقط مقدارهای نمایشی و موقت هستند؛ هنوز ذخیره نمی‌شوند و منو یا تعامل واقعی ندارند. تعمیرگاه، خرید خانه، شغل‌های قابل انتخاب و ذخیرهٔ بازی در نسخه‌های بعدی پیاده‌سازی می‌شوند.

## سازگاری
بر پایهٔ AML Plugin SDK است. SDK از GTA SA نسخهٔ 2.00 و نسخهٔ 2.10 (64-bit) پشتیبانی می‌کند. سازگاری با نسخه‌های دیگر تضمین نشده است.

## ساخت
GitHub Actions با Android NDK و AML PSDK فایل‌های افزونه را می‌سازد.

## نصب
این مخزن بازی GTA را توزیع نمی‌کند. برای استفاده به نسخهٔ قانونی و سازگار بازی و AML نیاز است. پیش از تغییرات از ذخیرهٔ بازی پشتیبان بگیر.
