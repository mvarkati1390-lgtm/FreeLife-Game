# ArSaCiA San Andreas RolePlay

پروژه آزمایشی سه‌بعدی و آفلاین برای Godot 4؛ شامل شهر ساده، جاده، ساختمان‌ها، بازیکن، خودروی نمونه و کنترل لمسی.

## وضعیت پروژه
این نسخه یک نمونه اولیه است، نه بازی کامل GTA San Andreas. از دارایی‌های اصلی GTA استفاده نمی‌کند و هنوز رانندگی واقعی، مأموریت‌های کامل، هوش مصنوعی شهروندان، خرید خانه و بازی آنلاین ندارد.

## اجرا
پروژه را با Godot 4.3 باز کنید و فایل `Main.tscn` را اجرا کنید.

## ساخت APK
در GitHub Actions از بخش Actions اجرای workflow با نام **Build Android APK** را انتخاب کنید. در صورت موفقیت، APK آزمایشی به‌عنوان Artifact با نام `ArSaCiA-Android-APK` در همان اجرای workflow قرار می‌گیرد.
