# FreeLife RP — Unity prototype

This is a separate Unity prototype. The existing Godot project at the repository root is unchanged.

## Requirements
- Unity **2022.3 LTS**
- Android Build Support, Android SDK & NDK, and OpenJDK modules for Android builds.

## Open
1. Open Unity Hub.
2. Choose **Add project from disk**.
3. Select the `UnityVersion` folder.
4. Open the project and press Play.

The first prototype creates a small original city at runtime. It includes a walkable player, a drivable test car, simple touch controls, a basic job reward and an on-screen cash display.

## Android
In Unity, open **File → Build Settings → Android → Switch Platform**, then build an APK. Android signing and device testing are still required.

## Important
This is an original prototype, not GTA San Andreas and not an ArSaCiA server client. It does not contain Rockstar/ArSaCiA proprietary source code, models, textures, maps, or audio. The city and gameplay code are newly written and currently very basic.
